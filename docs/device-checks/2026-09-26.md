## 手順 4. 確認項目

### C. 動画の書き出し

- ✓ Mac（Chrome）：Video で書き出しができる（ユーザー確認。codec は未記録）
- ✗ **ウィンドウを最大化していないと、Video のポップアップが見えない**（ユーザー報告）
  - 再現：Chrome のウィンドウを幅 900 px 以下にする → 実験画面の上部「Video」を押す → パネルが表示されない（最大化すると見える）
  - 原因の推定：幅 900 px 以下ではモバイル用のレイアウトになり、`.topbar` に `overflow-x: auto` が付く（`src/styles.css:656`）。CSS の仕様では、片方の軸が `visible` 以外になると、もう片方も `auto` になる。そのため、`.topbar` の下に `position: absolute` で出る `.video-panel`（`src/styles.css:1078`）がバーの中で切り取られる
  - 影響：**iPhone でも同じ理由で、実験画面の Video パネルが使えない可能性が高い**（未確認）
  - 修正案（別 PR）：モバイル用のレイアウトでは `.video-panel` を `position: fixed` にしてビューポート基準で出す。または、ポータルでトップバーの外に描画する
