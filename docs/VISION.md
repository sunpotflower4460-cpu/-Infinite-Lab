# Vision

π Infinite Lab は「数字の内部構造を観測する実験装置」です。

## 中心思想

> 美しさを先に作らない。正しい数字と正しい規則を先に作る。
> そして、正しい計算を続けた先に、どんな美しさが勝手に現れるのかを見る。

研究テーマは「π を描く」ことではなく、

```
Number → Rule → Structure
```

— 数列へ異なる幾何学的変換を与えたとき、どのような秩序が出現するか — の探索です。

## 原則

1. **数学的真正性**: 表示される図形は必ず実際の計算結果から生成する。事前に用意したアニメーション、π と無関係な模様、見栄えのための結果の改変、float 誤差の隠蔽はしない。
2. **表示 = 実行**: Inspector に表示される式は、実際に評価された式木そのもの。
3. **因果の追跡可能性**: 画面上のどの図形についても step / digit / 式 / 値 に遡れる。
4. **決定性**: 同じ Constant・Experiment・Parameters・Iteration なら、必ず同じ図形。乱数を使う場合は seed 必須。
5. **精度の正直さ**: 計算精度（桁数）と表示精度を分離し、float64 の箇所は float64 と明示する。
6. **分離**: Math Engine / Geometry Engine / Render Model / Renderer は互いに独立。Renderer は数学を知らない。

## 「無限」の扱い

真に無限回の計算はできません。UI の Infinite Mode は **Continuous computation**（停止するまで計算を続ける）と定義します（v0.3 予定）。v0.1 は計算済みの桁を使い切った時点で停止し、その旨を表示します。

## 完成イメージ

π を選び、Circle Chain を選び、Play を押す。数字が `3.141592653589…` と流れ始め、円が一つずつ描かれていく。
10 万回後に現れた構造の中の一つの円をクリックすると、`STEP 38,194 / π DIGIT 8 / ANGLE … / RADIUS … / POSITION …` が表示される。
巨大な模様の一本一本まで、数字へ遡れる。
